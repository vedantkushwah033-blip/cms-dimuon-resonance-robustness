# Milestones and acceptance gates

These are effort estimates, not promises of publication or admissions impact. Runtime and data feasibility may change them.

| Phase | Estimated focused effort | Deliverable | Acceptance gate |
|---|---:|---|---|
| Literature and feasibility | 1–2 weeks | Annotated prior-work matrix and verified dataset decision | Closest methods read; novelty narrowed or project stopped/reframed |
| Tiny-sample baseline | 1–2 weeks | Environment, loader, invariant-mass tests, selection log | Reproducible calculations and no unexplained mismatch |
| Full baseline reproduction | 2–4 weeks | Event selection, mass spectrum, provenance and validation | Trigger, data quality, known artifacts understood |
| Statistical procedure | 2–3 weeks | Frozen likelihood, statistic, fit diagnostics, failure policy | Independent technical review and predeclared choices |
| Pilot simulations | 1–2 weeks | Runtime profile, uncertainty, fit-failure report | Pilot passes and protocol frozen before main run |
| Main simulation and held-out validation | 2–6+ weeks | Results table, uncertainty intervals, sensitivity checks | Reproducible seeds, adequate precision, no selective reporting |
| Review and manuscript | 3–8+ weeks | Methods/results paper and reproducibility package | Claims match evidence and feedback is addressed |

## Priority order
1. Scientific correctness and provenance.
2. Reproducibility and independent validation.
3. Defensible contribution compared with prior work.
4. Clear writing, figures, and artifact quality.
5. Submission only to a venue that fits the completed work.

A journal acceptance, prestigious venue, external endorsement, or a 9/10 admissions rating cannot be guaranteed by a schedule or checklist.
